수치지형도(국토지리정보원 연속수치지형도) 비교 오버레이 — 내 컴퓨터에서만 처리
=================================================================

왜: 지금 지도는 OSM 도로 중심선 + 폭 추정이라 교차로·도로 가장자리 모양이 실제와 달라요.
    수치지형도(1:5000)의 '도로경계'를 지금 장면 위에 반투명으로 얹어서, 어디가 얼마나 다른지 바로 봅니다.
주의: 1:5000 국가기본도는 국외 반출이 제한돼요. 이 도구는 데이터를 어디로도 보내지 않고
      이 컴퓨터 안에서 유니티 폴더(Assets/PNU_Map3/NGII)에만 결과를 만듭니다.
      받은 원본은 Claude와 연결된 폴더(다운로드 폴더 등)가 아닌 곳, 예: D:\NGII_data 에 풀어 주세요.

1) 받기 (로그인·약관 동의는 직접)
   - 국토정보플랫폼 map.ngii.go.kr → 로그인 → 공간정보 → 수치지도 → 연속수치지형도(1:5,000)
   - 지역: 부산광역시 금정구, 동래구, 해운대구, 수영구, 남구 (코스가 지나는 5개 구)
   - 형식: SHP  (무료, 처음 받을 때 대용량 전송 프로그램 설치 안내가 나올 수 있어요)
   - 받은 압축을 D:\NGII_data 아래에 풀기(구별 하위 폴더 그대로 둬도 됨)

2) 만들기
   - Tools\ngii\run_ngii_overlay.bat 더블클릭 (처음 한 번 파이썬 패키지 설치로 1~3분)
     · 파이썬이 없으면 python.org 에서 3.11 설치("Add to PATH" 체크) 후 다시
     · 다른 폴더에 풀었으면: run_ngii_overlay.bat "D:\다른\폴더"
   - 결과: Assets\PNU_Map3\NGII\ngii_*.json, ngii_summary.txt(레이어 이름·개수만)
   - 유니티 메뉴 스크립트(PNUNgiiOverlay.cs)도 이때 Assets\PNU_Map3\Editor 에 복사돼요(이 도구를 쓸 때만).

3) 유니티에서 보기
   - 메뉴 PNU Map > NGII 오버레이 불러오기 (수치지형도 비교)
     · 하늘색 = 실제 도로 면, 청록 선 = 실제 도로 가장자리, 노란 선 = 도로중심선, 분홍 = 건물 자리
   - 메뉴 PNU Map > NGII 오버레이 켜기·끄기

4) 알려 주세요
   - ngii_summary.txt 내용(레이어 파일 이름·개수만 있음)과 보시기에 어떤지.
   - 레이어 코드(예: N3A_A0010000=도로경계)는 첫 실행 요약으로 확인해서 맞추면 돼요.
